## PROBLEM 2 — VOICE GUIDANCE / AUDIO FEEDBACK EVERYWHERE

The voice feature should be designed primarily for **elderly users and users with visual difficulty**.

### IMPORTANT CHANGE

**DO NOT require the user to speak commands to control the application.**

The user should interact with the app normally by **tapping buttons/options**.

Whenever the user taps something, the app should **speak and explain what they selected or what is currently on the screen**.

For example:

* User taps **Games** → app says: **"Games. You have 18 cognitive games available."**
* User taps **Progress** → app says: **"Progress. Your current progress is 75 percent."**
* User taps **Memory Match** → app says: **"Memory Match. This game helps you practice memory."**
* User taps **Yes** → app says: **"You selected Yes."**
* User taps **No** → app says: **"You selected No."**
* User taps **Next** → app says: **"Next question. Question 3 of 10."**
* User taps **Play** → app says: **"Playing the story."**
* User taps **Pause** → app says: **"Story paused."**
* User taps **Rewards** → app says: **"Rewards. You currently have 120 XP."**
* User taps **Back** → app says: **"Going back."**
